OpenScore String Quartets Catalogue

698 movements across 196 quartets by 63 composers. Click any column header to sort; use the search box to filter (across any field).

Score files are provided in several formats:

  1. MuseScore, for use in MuseScore studio (layout set out by us, manually),
  2. MusicXML, which is usable in almost any score reader (layout may be broken),
  3. PDF images (converted directly from the MuseScore, so layout should be correct).

Parts are provided in PDF only. These PDFs are made directly from the MuseScore; layout should be correct but there be occasional issues (please report any you come across).

External links are provided to:

  1. IMSLP.org for the source edition (PDF) on which ours is based.
  2. MuseScore.com to view and play online (but note that downloads are behind a paywall, so use the score/part download links instead)
  3. OurTextScores.com to view and even edit the mxl form online.
  4. YouTube.com to view a YouTube recording (available in most but not all cases).

We hope you enjoy this resource!

Mark Gotham, on behalf of the OSQ team.
