OpenScore String Quartets Catalogue

122 scores across 116 sets by 47 composers. Click any column header to sort; use the search box to filter (across any field).

Score files are provided in several formats:

  1. MuseScore, for use in MuseScore studio, (layout set out by us, manually),
  2. MusicXML, which is usable in almost any score reader, (layout may be broken),
  3. PDF images (converted directly from the MuseScore, so layout should be correct).

Parts are provided in PDF only. These PDFs are made directly from the MuseScore; layout should be correct but there be occasional issues (please report any you come across).

We hope you enjoy this resource!
